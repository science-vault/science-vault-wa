Privacy

How the current Learning Vault WA website handles information.

Current website

Learning Vault WA uses email/password accounts to manage access through the website. Both student and teacher accounts require approval from the site owner. Students provide a year group, and Years 11–12 students choose four or five subjects. Teachers receive a shareable class code. Account access can be changed or suspended by the owner. Files and website source hosted in the public GitHub repository remain publicly retrievable until protected hosting is configured.

Hosting and technical information

The website is hosted using GitHub Pages. Like most web hosting services, the hosting provider may process technical information required to deliver and secure the service. Any such processing is subject to the provider's own terms and privacy practices.

Account information

Accounts are handled by Google Firebase Authentication. Your email address, optional display name and authentication information are processed by Firebase to create accounts, verify email addresses, sign you in and support password resets. Passwords are sent directly to Firebase Authentication; they are not written into this website’s repository or stored as plain text by the website.

Cloud Firestore stores your account ID, email, display name, student/teacher account type, approval status, page permissions, year group, selected subjects, class code and account creation/update timestamps. The configured administrator can view account details and manage access. These records do not contain passwords or student results.

Firebase maintains sign-in session information in your browser. Selecting “Keep me signed in on this device” keeps that session across browser restarts. Without that selection, sign-in is limited to the browser session. Log out when using a shared device.

For approved students enrolled in an approved teacher’s class, Firestore stores submitted practice responses, automatically calculated practice marks, self-review counts, student-marked lesson completion and submission timestamps. Class teachers can see the saved work of students in their own class; the administrator can also access these records. These are classroom progress records, and browser-calculated practice scores are not verified examination grades. Joining a class shares saved progress with that teacher. Student-marked completion is identified separately from automatically checked scores.

For information on how Google processes authentication data, see Firebase privacy information.

External links

The website may link to third-party services. Learning Vault WA does not control the privacy practices of external websites.
