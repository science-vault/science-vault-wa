About Learning Vault WA

An organised resource library supporting Western Australian secondary teaching and learning.

Our purpose

Learning Vault WA brings teaching and learning materials into one searchable location so students and educators can find resources more efficiently. The collection covers Years 7–10 learning areas as well as senior secondary courses.

How the library is organised

Resources are organised by learning area, year or course, topic, resource type and source information where available. Dedicated vaults are provided for assessments, examinations and textbooks.

Independent resource library

Learning Vault WA is an independent educational resource website. It is not an official website of the Western Australian Department of Education, the School Curriculum and Standards Authority, or any publisher.

Keeping information useful

The library is continually developed. If you find an incorrect description, broken file or attribution issue, please use the Contact page.
